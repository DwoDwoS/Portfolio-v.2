# Portfolio - Elouan

Portfolio personnel en constante évolution développé dans le cadre de ma formation à **ADA Tech School Nantes**.

## À propos

Ce projet représente mon parcours d'apprentissage et mon évolution en tant que développeur Web/Concepteur d'Applications et Logiciels. Il sera régulièrement mis à jour avec de nouveaux projets, compétences et fonctionnalités au fur et à mesure de ma progression à ADA Tech School. Actuellement à la recherche d'une alternance d'un an pour valider mon RNCP IV.

## Technologies utilisées

- **Framework** : Next.js
- **Langage** : TypeScript
- **Styling** : Tailwind CSS
- **Icônes** : Font Awesome
- **Formulaire** : Formspree

## Fonctionnalités

- Page d'accueil avec présentation et compétences
- Section Portfolio avec projets réalisés
- Page À propos
- Formulaire de contact fonctionnel
- Design moderne avec effet glassmorphism
- Interface responsive (mobile, tablette, desktop)
- Navigation fixe avec menu burger mobile
- Accessibilité (ratios de contraste WCAG AAA)

## Structure du projet

```
portfolio/
├── app/                   # Pages Next.js (App Router)
│   ├── page.tsx           # Page d'accueil
│   ├── about/             # Page À propos
│   ├── portfolio/         # Page Portfolio
│   └── contact/           # Page Contact
├── components/            # Composants réutilisables
│   ├── Navbar.tsx
│   ├── Footer.tsx
│   ├── Projects.tsx
│   └── ContactForm.tsx
└── public/               # Assets statiques
```
